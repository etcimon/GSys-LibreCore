Upgrade Program

GSys LibreCore evolves the baseline OpenHW CVA6 core through a ranked upgrade program. Features are config-gated: minimal targets keep identity with the classic in-order machine; production profiles opt into wider issue, OoO, SMT, L2/L3, hypervisor, and server math packages.

Authority and status detail live under monorepo architecture/ (not flisted RTL). This page is the product map for humans and agents.

Layering principle

Classic in-order CVA6  (OoOEn=0, NrHarts=1, L2En=0, …)
        │  opt-in packages / knobs
        ▼
Wider issue → slice OoO → full OoO
        │
        ▼
SMT (shared pipeline, banked arch state)
        │
        ▼
L2 / L3 / server prefetch (APU memory side)
        │
        ▼
H + Sstc + server math / RVV packages

Never enable a wide stack without the SoC-readiness checklist (AGENTS.md §0.2): config gate, verify target, DFT, observability, DTS when software-visible.

Operator enable (examples)

Package names evolve; treat these as illustrative and confirm against core/include/*_config_pkg.sv and .config.ts soc.coreConfig.

# In-order dual-issue-style / default Linux-class 64b
g6lc-build config   # inspect soc.coreConfig
 
# Full OoO production lite / server
#   g6lc64_ooo  |  g6lc64_ooo_server
g6lc-build verify --target g6lc64_ooo
g6lc-build test --suite ooo-l3-tests   # optional, lengthy
 
# SMT2
#   g6lc64_smt2
g6lc-build verify --target g6lc64_smt2
 
# Server math (H, Sstc, L2 auto, …)
#   g6lc64_server_math  |  g6lc64_server_math_v (RVV when Ara linked)

What “production gated” means

  • Production: intended for real targets; tested under named packages.
  • Gated: default or minimal configs keep the feature off so netlists stay identity with the classic path unless a package opts in.
  • Optional suites (e.g. ooo-l3-tests, full Linux SMT payloads) may be excluded from default verify for runtime cost, not because the RTL is “experimental.”

Structural timing

Frequency risk grows with issue width and OoO depth. Use sv-timing / g6lc-build timings for early structural FO4 feedback. It does not replace STA on the target library.
