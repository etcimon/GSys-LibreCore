# boot-hazards.md — register of hazards the deeper pipeline adds (for the later OpenSBI / Linux bring-up)

<!-- hyp8-status -->
> **Status: indicative, subject to further information.** Goal: 8 FO4 per cycle (5 GHz nameplate at
> `fo4_ps = 20`, margin 0.2). Nothing in the hyp8 trees has been linted, simulated or measured; this
> register is what the bring-up starts from. Each entry: hazard, where it lives, what a fix must check.

| # | Hazard | Where | What the bring-up must check |
|---|---|---|---|
| H1 | FENCE.I / SFENCE.VMA / satp change must drain fetch, decode (D1–D3), realign/scan, the TLB pipeline (T1–T3) and the I$ response stages before refetch | `controller` (counted drain), `g6lc_core` wiring | the drain count ≥ the deepest in-flight stage; a stale translation or stale instruction bytes after the fence are the symptom |
| H2 | Interrupt injection and `dcsr.step` against the registered commit bundle | `commit_stage`, `csr_regfile` (`csr_irq`) | an interrupt taken on a bundle whose side effects already fired; single-step must stop after exactly one retired instruction |
| H3 | Precise exceptions across the IQ replay window: a dependent woken speculatively (load countdown) must not have published/committed when the load replays — WIRED: `load_unit.replay_o/replay_tid_o` on a missed hit window + `g6lc_lsq.replay_valid_o/tid_o` merge in `g6lc_ooo_dispatch` into `g6lc_iq.replay_valid_i/tid_i` (pending-TID mask, bank-wide re-arm) | `g6lc_iq_bank` (re-arm), `scoreboard` (`ld_checked`), `load_unit`, `g6lc_lsq_verdict` | no commit of an instruction whose source was a replayed load's stale value; `ld_checked` gate before commit; every coincident replay tid survives via `rp_mask_q` |
| H4 | Epoch kill vs the 2-bit I$ token: two override distances (BTB check at F2, predictors at F4+) and the commit redirect record | `frontend`, `g6lc_ftq`, `g6lc_fdip`, `instr_queue` | no instruction from a killed epoch reaches decode; no token reuse while a killed response is in flight (token width may need to grow with the depth) |
| H5 | Speculative-wakeup countdown vs variable-latency producers (DIVSQRT, serdiv, loads that miss) — WIRED: `load_unit` raises `replay_o` when the expected hit slot (2 + DcacheHitExtra) passes without data | `g6lc_ooo_pkg` latency classes, `g6lc_iq_bank`, `load_unit` age window | variable-latency classes must be `LAT_NONSPEC` (wake on real WB); a miss must raise replay for every speculative dependent; a late D$ hit on the same cycle as the replay pulse must not double-wake |
| H6 | Writeback-lane reservation starvation (`WbReserve`) | `issue_read_operands`, `ex_stage` | an op that can never find a free lane slot (fairness); the reservation table must be cleared on flush/cancel |
| H7 | `ld_checked` vs non-idempotent (device) loads at the commit head | `load_unit`, `g6lc_lsq_publish`, `scoreboard` | the head rule (`no_st_pending`, `wbuffer_not_ni`) still applies before the device read is issued; a checked bit must never let a device load issue early |
| H8 | AMO through the elastic miss-unit request stage | `wt_dcache_missunit`, `store_unit` | one AMO in flight; the elastic stage must not reorder an AMO with a preceding store; ack semantics of the registered packet |
| H9 | Three-cycle store→load forward vs partially overlapping stores (byte-exact merge across both queues and the pending write-buffer record) | `store_buffer` (F1–F3), `wt_dcache_wbuffer` (pending export), `load_unit` publish | the `forward_possible` bit must be 0 whenever any covering byte comes from an entry without data; the merge order (youngest writer per byte) must match today's |
| H10 | Staggered ALU: the high half of a forwarded result arrives one cycle after the low half | `alu`, `issue_read_operands` bypass, `g6lc_iq` class table | shifts/compares/`slt`/branches that need all 64 bits must be classed `LAT_ALU_FULL`; a consumer classed `LAT_ALU_LOW` must only use the low half in its first stage |
| H11 | `recovering_q` (rename restore + repair) vs an older redirect in the gap | `g6lc_rename_recover`, `g6lc_ooo_dispatch` | the older redirect wins by age; `enable_i` low in every recovery cycle (A147 invariant); free-list picks returned exactly once |
| H12 | RVFI ordering with the commit bundle (+1) and the two-step CSR read | `g6lc_rvfi_probes`, `g6lc_rvfi` | the RVFI order equals the retirement order; CSR read values reported after the write of the same op |
| H13 | CDC seam reset ordering in the APU (`axi_cdc`, two-flop syncs) | `g6lc_hart` (ex `the core` wrapper), APU tree | both domains leave reset with the CDC FIFOs empty; same clock in the draft, so only the reset sequence is live |
| H14 | CSR side effects that must precede the next fetch (xRET, `satp`, `mstatus.MPRV`, PMP writes) with the two-step CSR read/write | `csr_regfile` (C1–C3), `controller`, `frontend` redirect record | the flush request is raised after the write lands (t+2), never before |
| H15 | PMP check two stages after the access decision (TLB T3 step) | `pmp*`, `g6lc_tlb`, `load_unit`/`store_unit` | an access that fails PMP must not have had a side effect (device read issued, store buffer accepted) before the verdict |
| H16 | Bank steering vs CSR age order and commit-head classes (fence/system/AMO/CVXIF) | `g6lc_iq_arb`, `g6lc_iq_legal` | the legality bits are recomputed one cycle late in the conservative direction only; CSR-in-age-order and head-only classes hold across banks |
| H17 | Commit bundle vs drop/replay of a cancelled slot presented at t and acked at t+1 | `scoreboard`, `commit_stage` | a slot cancelled between t and t+1 must retire as drop; the architectural map must not be updated for it |
| H18 | Elastic `instr_queue` and FTQ epochs vs `replay_q` reseed (the FtqDepth != 0 finding) | `frontend`, `instr_queue` | a refused window must be refetched exactly once; no silent frontend after a reseed |
| H19 | Multiplier latency parameter co-emission (8 stages) vs the owner table and the IQ class table | `mult`, `multiplier`, `g6lc_ooo_pkg` | all three read the same `MultStages`; a cancelled multiply's late result is suppressed over the longer window |
| H20 | The registered `cancelled_mask` (one cycle after the resolve) vs a WB that lands in the resolve cycle | `scoreboard`, PRF write gate, owner tables | a to-be-cancelled op's WB in the resolve cycle writes the PRF but its slot is dropped and the register freed by the drop path (today's A112 semantics, now pervasive) |
| H21 | LSQ `wait`-verdict replay WIRED: `g6lc_lsq_verdict` fires `replay_valid_o/replay_tid_o` on a load `wait` verdict (older unresolved store / matched store without data), not only on violation; the load's dependents that were countdown-woken are re-armed | `g6lc_lsq_verdict`, `load_unit` publish, `issue_stage`/`g6lc_ooo_dispatch` replay merge | a wait verdict now re-arms speculatively woken dependents — verify no double re-arm when the wait resolves to a clean verdict next cycle |
| H22 | `mem_stall` tied low at the issue boundary — loads are accepted (acked) even with `stl_stall` high and held inside `load_unit` | `load_unit` accept, `issue_stage`/`g6lc_iq` hold-until-ack | the IQ must never hang on a held load; a store-storm must not starve the accepted load inside the unit |
| H23 | ALU2 steering disabled under `WbReserve` | `issue_read_operands` steering, `ex_stage` | ops steered to ALU1 only while reservation is active; no op silently loses its second-issue-lane option |
| H24 | `dec_adv` all-or-nothing drain: a partial decode advance cannot leave the head block half-consumed | `id_stage`/`g6lc_decode` advance, `controller` drain | after the counted drain the fetch/decode frontier is exact — no double-issue or skipped instruction of the draining block |
| H25 | Macro FSM across flush (multi-step uop/macro sequences) | `id_stage` macro FSM, `controller` | an in-flight macro sequence must restart cleanly after flush — no mid-sequence resume with stale state |
| H26 | RAS restore epoch race: a restore written while an older redirect is still resolving | `g6lc_ras`/`frontend` restore record | the older redirect's RAS wins; a restore must not resurrect return addresses from a killed epoch |
| H27 | Performance events WIRED: `frontend.hyp_fe_override{1,2}_o` (override-stage taken pulses) and `g6lc_iq_arb.hyp_wb_reserve_stall_o` (ready candidate not taken only because its WB/FLU slot was reserved) route through `issue_stage`/`g6lc_core` to `perf_counters`; tie-offs removed | `perf_counters`, `g6lc_core`, `frontend`, `g6lc_iq_arb` | pulse timing vs the event's cycle semantics — an override pulse counts the cycle the override fires, not the cycle the mispredict is confirmed |
| H28 | APU-side +1/+2 latencies vs software-visible register semantics: CLINT MTIP +1, PLIC verdict +1, timer irq +1, APB timer access +1 wait state, DM slave window +3 (dm_mem registered request decode), bootrom read +2, hart irq/debug two-flop sync | `clint`, `plic_top`, `apb_timer`/`timer`, `dm_top`/`dm_mem`, `bootrom`, `g6lc_hart` | level-interrupt +1 is invisible to SW; the debug probe must tolerate the +3 window latency (accesses still ordered; bridge `RD_LAT=4` covers it); MTIP edge timing shifts one cycle (check timecmp-programmed tick alignment) |
| H29 | DMI request decode registered inside `dm_csrs` (+1 response latency) and `dm_mem` request bundle registered (+1 window latency); serial `dmi_jtag` interior unchanged (raw POR reset, own clock domain) | `dm_csrs` (`req_q`/`req_v_q`), `dm_mem` (`req_q` bundle), `g6lc_axi2mem_reg` `RD_LAT=4` | DTM/DM valid/ready handshake unchanged — a debugger retry or timeout accounting for one extra response cycle; `dmi_req_ready_o` now gates on `req_v_q` so at most one request sits in the decode stage |
| H30 | Trigger CSR write -> match visibility +1 (r4): `trigger_module` match logic now reads the registered `*_q` trigger-record state; a `csr tdata*` write takes effect for matching one cycle later — safe iff every CSR write to a trigger register serializes/flushes the pipe before any instruction that could match on the new value is fetched | `trigger_module` (`*_q` record state), `csr_regfile` write path, `controller` serialize-on-CSR-write | an instruction fetched in the same window as the CSR write must not match the stale trigger value; mcontrol `e_matched` chain prefix preserved inside the match unit |
| H31 | Banked freelist starvation (r4): `g6lc_rename_read` lane p picks only from bank p%FL_BANKS; a lane whose own bank is empty stalls the whole group even if other banks hold free registers | `g6lc_rename_read` (`bank_mask`, per-lane `alloc_ok`), `g6lc_rename` (`FL_BANKS=HypCfg.FreelistBanks`) | sustained single-bank depletion (e.g. every freed index even while lane 0 demands) must drain via the stall, never pick a foreign-bank duplicate; res_pick_mask gathers actual takes only |
