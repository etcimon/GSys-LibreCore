Spec quotation

"The single-letter V extension is intended for use in application
processor profiles. The misa.V bit is set for implementations providing
misa and supporting V. The V vector extension has precise traps. The V
vector extension depends upon the Zvl128b and Zve64d extensions."
(specs/riscv-spec.html:38873-38880, anchor #ext:v)

The V extension adds a vector register file, vector instruction formats, and a rich set of load, store, integer, fixed-point, floating-point, reduction, permutation, and mask operations. It is a major microarchitectural subsystem: it requires a vector register file, vector ALUs, memory unit with strided/segmented/indexed access, and length polymorphism (VLEN, SEW, LMUL). CVA6 does not implement a full in-pipeline V unit; RVV is provided by attaching an external vector unit (PULP Ara) at the accelerator seam, which is mutually exclusive with CVXIF.
