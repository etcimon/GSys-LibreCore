Vol II §4.6 — Sv57: Page-Based 57-bit Virtual-Memory System

Canonical: specs/riscv-spec.html#sv57. Domain: RAM.

Sv57 adds a fifth page-table level to support 57-bit virtual addresses with 4 KiB pages. It is the largest RV64 paging mode and further increases translation latency and page-table memory. It is intended for systems for which a 48-bit virtual address space is insufficient. Implementations that support Sv57 must also support Sv48.

Spec quotation

"This section describes a simple paged virtual-memory system designed for
RV64 systems, which supports 57-bit virtual address spaces. Sv57 is
intended for systems for which a 48-bit virtual address space is
insufficient. It closely follows the design of Sv48, simply adding an
additional level of page table, and so this chapter only details the
differences between the two schemes. Implementations that support Sv57
must also support Sv48."
(specs/riscv-spec.html:79680-79694, anchor #sv57 / #norm:Sv57_sxlen)

CVA6 status: configurable but likely unverified. The mode enum includes ModeSv57 = 10 at core/include/config_pkg.sv:50, and the PTW is parameterized by CVA6Cfg.PtLevels so a fifth level can be elaborated in core/cva6_mmu/cva6_ptw.sv:120-200. No shipped 64-bit target sets MODE_SV = ModeSv57, so while the code structure supports five levels, it has not been verified as a tape-out configuration.

.dts linkage: a Sv57 target would report mmu-type = "riscv,sv57"; the memory@ map and PPNW must be wide enough for the 57-bit virtual address space.
