Vol II §4.1 — Supervisor CSRs

Canonical: specs/riscv-spec.html#_supervisor_csrs. Source line: specs/riscv-spec.html:77065. Domain: RAM.

This subchapter enumerates the supervisor-mode control and status registers: sstatus, sie, sip, stvec, sscratch, sepc, scause, stval, satp, and the counter-enable CSRs. They are the privileged-state interface for virtual memory, interrupts, and exceptions visible to the OS. Any feature touching paging or S-mode interrupts must update these CSRs.

Spec quotation

"A number of CSRs are provided for the supervisor."

CVA6 status: implemented. Supervisor CSRs are read/written in core/csr_regfile.sv; satp is consumed by the MMU/PTW in core/cva6_mmu/cva6_mmu.sv and core/cva6_mmu/cva6_ptw.sv. sstatus, sie/sip, stvec, sepc/scause/stval participate in trap entry and return in core/controller.sv.

.dts linkage: S-mode presence and the paging mode are advertised by the CPU riscv,isa string (e.g. _s or ...s...) and mmu-type (e.g. riscv,sv39); these must match the satp mode field.
