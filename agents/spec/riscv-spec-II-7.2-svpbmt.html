Vol II §7.2 — Svpbmt Extension for Page-Based Memory Types

Canonical: specs/riscv-spec.html#ext:svpbmt. Source line: specs/riscv-spec.html:88171. Domain: CACHE, RAM.

Svpbmt adds page-table-encodable memory-type attributes (PMA-like cacheability, idempotency, and ordering) in the PTE bits. It lets the OS set memory types per page rather than only via static PMA regions. This decouples memory-type configuration from physical regions and interacts with the TLB and cache allocation/flush policies.

Spec quotation

"In Sv39, Sv48, and Sv57, bits 62-61 of a leaf page table entry indicate
the use of page-based memory types that override the PMA(s) for the
associated memory pages. The encoding for the PBMT bits is captured in
Table 149. The Svpbmt extension depends on the Sv39 extension."
(specs/riscv-spec.html:88171-88176, anchor #ext:svpbmt)
