The scalar cryptography extensions include the NIST suite (Zkn: AES, SHA-256, SHA-512, SHA-256 SIG0/1, etc.), the Shangmi suite (Zks: SM3/SM4), and the entropy source (Zkr). They add new instructions that operate on the integer register file or special entropy CSRs. They are implemented as dedicated functional units alongside the ALU.

CVA6 status: partial. The CVA6Cfg.ZKN bit in core/include/config_pkg.sv enables the scalar AES functional unit. The decoder routes AES instructions when CVA6Cfg.ZKN is set (core/decoder.sv:1849), and the issue stage drives aes_valid_o (core/issue_read_operands.sv:69-70,770-771). The AES unit itself is core/aes.sv; original instruction bits for AES are captured at core/issue_read_operands.sv:1080-1082. The Zkr entropy-source CSR, Zks ShangMi instructions, and vector cryptography (zvk*) are not implemented. (U10ᵇ Ara RVV attach covers base V/Zve* compute paths, not Zvk* — see Vol I ch9.)

.dts linkage: the CPU riscv,isa string advertises _zkn when CVA6Cfg.ZKN is set; Zkr/Zks/Zvk would be added when implemented.
