Vol I chapter 6 — Floating-Point Extensions

Canonical anchors: #ext:f (6.1 F), #ext:d (6.2 D), #ext:q (6.3 Q), #ext:zfh (6.4 Zfh), #ext:zfa (6.6 Zfa), #ext:zfinx (6.8 Zfinx/Zdinx/Zhinx). Source lines: specs/riscv-spec.html:15605 (F), :16455 (D), :16767 (Q), :16910 (Zfh), :17142 (Zfa).

This chapter defines the F (single), D (double), Q (quad), and H/Zfh (half) precision floating-point extensions, the shared floating-point CSR (fcsr, frm, fflags), rounding modes, and NaN boxing. FP is a large architectural island: the decoder, register file, issue/execute units, and write-back must support a separate FP register file and control/status state.

Spec quotation

"This section describes the F standard extension for single-precision
floating-point, which adds computational instructions compliant with
the IEEE 754-2008 arithmetic standard's binary32 format and operations.
The F extension depends on the Zicsr extension."
(specs/riscv-spec.html:15605-15612, anchor #ext:f)

F adds 32 floating-point registers, f0–f31, and the fcsr CSR; D expands the registers to 64 bits (FLEN=64) and adds double-precision instructions; Q further expands to 128 bits; Zfh adds half-precision; Zfa adds additional FP instructions; Zfinx/Zdinx/Zhinx use the integer register file for FP values.

CVA6 status: implemented when configured via CVA6Cfg.RVF/RVD/RVQ/RVZfh/RVZfa/RVZfinx in core/include/config_pkg.sv and the per-target packages. The decoder classifies FP operations in core/decoder.sv:1849-1850 (orig-instr preservation for CVXIF/FP/ZKN). The FPR issue/read-operand path is in core/issue_stage.sv:310-315 and core/issue_read_operands.sv:129-137; the FPU wrapper is core/fpu_wrap.sv and the CVFPU implementation lives under core/cvfpu/ (e.g. fpnew_classifier.sv). The FP CSRs fflags/frm/fcsr are defined in core/include/rvfi_types.svh:39-41 and read/written in core/csr_regfile.sv.

.dts linkage: the CPU riscv,isa string reflects F/D/Q/Zfh/Zfa/Zfinx extensions; status = "okay" and the chosen ISA string must match the CVA6Cfg.RVF/RVD/RVQ/RVZfh bits.
