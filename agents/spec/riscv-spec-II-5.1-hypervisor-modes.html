Vol II §5.1 — Privilege Modes

Canonical: specs/riscv-spec.html#_privilege_modes. Source line: specs/riscv-spec.html:79829. Domain: —.

The H extension adds two new operating modes: VS (virtual supervisor) and VU (virtual user), plus the HS-mode hypervisor. These modes let a hypervisor run guest OSes with their own S/U privilege levels while trapping sensitive operations to the hypervisor. Correct implementation requires a new privilege encoding, virtual interrupt handling, and two-stage translation.

Spec quotation

"The current virtualization mode, denoted V, indicates whether the hart
is currently executing in a guest. When V=1, the hart is either in
virtual S-mode (VS-mode), or in virtual U-mode (VU-mode) atop a guest OS
running in VS-mode. When V=0, the hart is either in M-mode, in HS-mode,
or in U-mode atop an OS running in HS-mode."
(specs/riscv-spec.html:79829-79839, anchor #_privilege_modes)
