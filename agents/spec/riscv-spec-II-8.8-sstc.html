Vol II §8.8 — Sstc Extension for Supervisor-mode Timer Interrupts

Canonical: specs/riscv-spec.html#Sstc. Source line: specs/riscv-spec.html:88824. Domain: —.

Sstc provides supervisor-level timer CSRs (stimecmp, stimecmph) and a supervisor timer interrupt, removing the need for S-mode to delegate the M-mode timer interrupt. It allows the OS to manage timer interrupts directly and improves virtualization latency.

Spec quotation

"The current Privileged arch specification only defines a hardware
mechanism for generating machine-mode timer interrupts (based on the
mtime and mtimecmp registers). With the resultant requirement that timer
services for S-mode/HS-mode ... have to all be provided by M-mode - via
SBI calls from S/HS-mode up to M-mode."
...
"The Sstc extension defines supervisor-level timer interrupts.
The Sstc extension provides a facility for supervisor-mode software to
receive timer interrupts through the stimecmp and stimecmph registers."
(specs/riscv-spec.html:88824-88835, anchor #Sstc)
