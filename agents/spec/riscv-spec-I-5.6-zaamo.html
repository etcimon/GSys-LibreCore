Vol I §5.6 — Zaamo Extension for Atomic Memory Operations

Canonical: specs/riscv-spec.html#ext:zaamo. Domain: RAM, CACHE, SPEC.

Zaamo defines the AMO instructions (AMOSWAP/ADD/AND/OR/XOR/MIN/MAX/MINU/MAXU) operating on aligned word/doubleword/quadword. They atomically load a data value from the address in rs1, place the value into register rd, apply a binary operator to the loaded value and the original value in rs2, then store the result back to the original address in rs1. AMOs support acquire/release ordering bits. For RV64, 32-bit AMOs always sign-extend the value placed in rd and ignore the upper 32 bits of rs2.

Spec quotation

"The atomic memory operation (AMO) instructions perform read-modify-write
operations for multiprocessor synchronization and are encoded with an
R-type instruction format. These AMO instructions atomically load a data
value from the address in rs1, place the value into register rd, apply a
binary operator to the loaded value and the original value in rs2, then
store the result back to the original address in rs1. AMOs can either
operate on doublewords (RV64 only) or words in memory. For RV64, 32-bit
AMOs always sign-extend the value placed in rd, and ignore the upper 32
bits of the original value of rs2."
(specs/riscv-spec.html:14907-14940, anchor #ext:zaamo / #norm:amo_operand_size)
