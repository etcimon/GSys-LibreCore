Vol III §6 — RVB23 Profiles

Canonical anchors: #_rvb23u64_profile (6.1), #_rvb23s64_profile (6.2). Source lines: specs/riscv-spec.html:92061 (6.1), :92388 (6.2).

RVB23 is the 2023 embedded/bare-metal profile. It is a superset-oriented profile for high-performance embedded processors, including RVA23 features plus additional embedded-specific extensions. It is less commonly the direct target for CVA6, but embedded CVA6 variants may align with RVB23U64.

Spec quotation

"The RVB23U64 profile specifies the ISA features available to user-mode
execution environments in 64-bit RVB applications processors."
...
"The RVB23S64 profile specifies the ISA features available to a
supervisor-mode execution environment in 64-bit applications processors.
RVB23S64 is based on privileged architecture version 1.13."

CVA6 status: not explicitly targeted. Individual RVB23 extension bits may be configured in per-target packages, but no shipped target is verified as a full RVB23S64 configuration.

.dts linkage: the CPU riscv,isa string should not claim RVB23 unless the target package and verification explicitly cover every mandatory and optional extension in the profile.
