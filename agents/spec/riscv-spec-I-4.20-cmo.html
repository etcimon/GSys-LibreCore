Vol I §4.20 — Cache Management Operations (CMOs)

Canonical: specs/riscv-spec.html#cmo (source line 12653). Domain: CACHE, RAM.

Cache management operation (CMO) instructions perform operations on copies of data in the memory hierarchy, generally on cached copies. CMOs are grouped into management (inval/clean/flush), zero (CBO.ZERO), and prefetch (CBO.PREFETCH) classes. The Zicbom extension defines CBO.INVAL, CBO.CLEAN, and CBO.FLUSH for aligned 64-byte blocks; Zicboz adds CBO.ZERO; Zicbop adds CBO.PREFETCH. CMOs require privilege and PMA checks and can replace heavyweight fence/flush sequences for DMA coherence.

Spec quotation

"Cache management operation (CMO) instructions perform operations on
copies of data in the memory hierarchy. In general, CMO instructions
operate on cached copies of data, but in some cases, a CMO instruction
may operate on memory locations directly. Furthermore, CMO instructions
are grouped by operation into the following classes:
  - A management instruction manipulates cached copies of data with
    respect to a set of agents that can access the data.
  - A zero instruction zeros out a range of memory locations, potentially
    allocating cached copies of data in one or more caches.
  - A prefetch instruction indicates to hardware that data at a given
    memory location may be accessed in the near future, potentially
    allocating cached copies of data in one or more caches."
(specs/riscv-spec.html:12653-12673, anchor #cmo / #intro-cmo)
