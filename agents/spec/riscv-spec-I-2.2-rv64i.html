Vol I §2.2 — RV64I Base Integer Instruction Set

Canonical: specs/riscv-spec.html#rv64. Source line: specs/riscv-spec.html:5284. Domain: RAM.

RV64I extends RV32I with 64-bit integer operations: LWU, LD, SD, and the 64-bit arithmetic instructions (ADDW/ADDIW/SUBW/etc.) and shifts. It establishes XLEN=64 for the general-purpose registers and memory addresses. It is the base for the Linux-class configurations (e.g. cv64a6_imafdc_sv39_config_pkg.sv) and for the Sv39/Sv48 virtual-memory modes.

Spec quotation

"RV64I builds upon RV32I, adding 10 instructions and changing the width
of integer registers to 64 bits."
...
"The integer base supports the execution environment that runs on a
RISC-V hart and supports the execution of software written in compiled
high-level languages."

CVA6 status: implemented. The 64-bit ALU in core/alu.sv executes ADDW/SUBW/SLLW/SRLW/SRAW/ADDIW and sign-extends 32-bit W-suffix results; the load/store unit handles LWU/LD/SD in core/load_store_unit.sv. The decoder classifies RV64I opcodes in core/decoder.sv. CVA6Cfg.XLEN=64 is selected by core/include/cv64a6*_config_pkg.sv targets.
