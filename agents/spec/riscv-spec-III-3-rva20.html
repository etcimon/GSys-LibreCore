Vol III §3 — RVA20 Profiles

Canonical anchors: #_rva20u64_profile (3.1), #_rva20s64_profile (3.2). Source lines: specs/riscv-spec.html:90395 (3.1), :90621 (3.2).

RVA20 is the first application-processor profile. RVA20U64 requires RV64I, M, A, F, D, C, Zicsr, Zifencei, and a set of Zic* extensions. RVA20S64 adds S-mode and Sv39 paging. It is the baseline for 64-bit Linux application processors and directly maps to a CVA6 Linux configuration.

Spec quotation

"The RVA20U64 profile specifies the ISA features available to user-mode
execution environments in 64-bit applications processors. This is the
most important profile within the application processor family in terms
of the amount of software that targets this profile."
...
"The RVA20S64 profile specifies the ISA features available to a
supervisor-mode execution environment in 64-bit applications processors.
RVA20S64 is based on privileged architecture version 1.11."

CVA6 status: configurable. Targets like core/include/cv64a6_imafdc_sv39_config_pkg.sv match RVA20S64 by setting RVA/RVC/RVF/RVD/RVA/RVM and RVS/RVU with Sv39. The riscv,isa string in the generated DT must reflect those bits.

.dts linkage: the CPU riscv,isa string for an RVA20S64 CVA6 is rv64imafdc_zicsr_zifencei plus any implemented Zic*; mmu-type is riscv,sv39.
