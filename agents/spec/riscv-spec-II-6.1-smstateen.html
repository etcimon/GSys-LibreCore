Vol II §6.1 — Smstateen and Ssstateen Extensions

Canonical: specs/riscv-spec.html#smstateen. Source line: specs/riscv-spec.html:83524. Domain: —.

Smstateen/Ssstateen provide per-extension state-enable bits in M-mode (mstateen*) and S-mode (sstateen*) CSRs. They allow M-mode to selectively disable or enable stateful extensions for lower privilege levels, which is important for context switching and virtualization of stateful user-mode extensions.

Spec quotation

"The implementation of optional RISC-V extensions has the potential to
open covert channels between separate user threads, or between separate
guest OSes running under a hypervisor. The problem occurs when an
extension adds processor state that the main OS or hypervisor is unaware
of (and hence won't context-switch) but that can be modified/written by
one user thread or guest OS and perceived/examined/read by another."
(specs/riscv-spec.html:83524-83532, anchor #smstateen)

CVA6 status: absent. No mstateen* or sstateen* CSRs are implemented in core/csr_regfile.sv; context-switch save/restore is performed by software for the existing extension state.

.dts linkage: no DT node; Smstateen/Ssstateen would be advertised in the riscv,isa string if implemented.
