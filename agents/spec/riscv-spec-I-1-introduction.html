Chapter 1 introduces the RISC-V module nomenclature (e.g. I, M, A, F, D, G), the hardware platform terms (hart, agent, coprocessor), and the foundational trap and memory-model vocabulary. It is the context for all subsequent implementation work: every feature must map to the right extension letter and must preserve the precise-trap, byte-addressable-memory, and XLEN abstraction introduced here.

CVA6 status: not a hardware feature. The chapter's nomenclature is realized in the per-target config packages (core/include/cv*a6*_config_pkg.sv) and in the riscv,isa string produced for the device tree. The CVA6 top-level (core/cva6.sv) instantiates the hart, debug, interrupt, and reset agents described here.

.dts linkage: the top-level device tree declares the hart(s), interrupt controller, clocks, and reset. The riscv,isa string is built from the nomenclature of this chapter and must match the config extension bits.
