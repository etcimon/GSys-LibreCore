Vol I §1.4 — Memory

Canonical: specs/riscv-spec.html#sec:intro-memory. Domain: RAM.

The §1.4 objective is to define the address space abstraction: a RISC-V hart has a single byte-addressable address space of 2XLEN bytes, with a byte of 8 bits. Loads and stores are defined on this flat space; the canonical split between main memory and memory-mapped I/O is not part of the ISA itself but is realized by Physical Memory Attributes (II 3.6). This anchors all later memory-model, cache, and MMU discussion.

Pseudo-SystemVerilog synthesis notes

module address_space #(parameter int XLEN)(
  input  logic [XLEN-1:0] addr_i,
  input  logic            load_i, store_i, fetch_i,
  // main memory / MMIO split is a PMA attribute, not an address-space difference
  output logic            main_memory_o, mmio_o
);
  // byte addressable, no ISA-imposed holes
endmodule
