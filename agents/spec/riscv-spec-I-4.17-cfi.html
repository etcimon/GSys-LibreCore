Vol I §4.17 — Control-Flow Integrity (CFI)

Canonical: specs/riscv-spec.html#unpriv-cfi (source line 11109). Domain: BP.

CFI provides hardware-assisted defense against ROP/COP/JOP by enforcing landing-pad constraints on indirect jumps/calls and by using a shadow stack for returns. It constrains the branch predictor and return-address stack: a mispredicted return or jump to a non-landing-pad target is an architectural violation, not just a performance event. The unprivileged chapter defines the user-visible aspects; privileged controls are in II 6.9.

Pseudo-SystemVerilog synthesis notes

module cfi_check (
  input  logic [XLEN-1:0] target_i,
  input  cfi_instr_e      kind_i,        // call/return/jump
  input  logic            shadow_stack_match_i,

);
  // indirect jumps must target landing pads; returns match shadow stack
endmodule
