Vol III §4 — RVA22 Profiles

Canonical anchors: #_rva22u64_profile (4.1), #_rva22s64_profile (4.2). Source lines: specs/riscv-spec.html:90764 (4.1), :91130 (4.2).

RVA22 extends RVA20 with newer extensions: Zicbom, Zicbop, Zicboz, Zicsr/Zifencei remain; it adds Zba, Zbb, Zbs, Zfhmin, Zicond, Zihintpause, Zihintntl, and others. RVA22S64 also adds Svadu, Svpbmt, and Svinval. It represents the 2022 application-processor target and drives feature roadmaps for CVA6 additions.

Spec quotation

"The RVA22U64 profile specifies the ISA features available to user-mode
execution environments in 64-bit applications processors. This is the
most important profile within the application processor family in terms
of the amount of software that targets this profile."
...
"The RVA22S64 profile specifies the ISA features available to a
supervisor-mode execution environment in 64-bit applications processors.
RVA22S64 is based on privileged architecture version 1.12."

CVA6 status: partial. Some RVA22 bits are configurable: RVB (Zba/Zbb/Zbs) in core/alu.sv and decoder; RVZiCond in core/decoder.sv/core/alu.sv; RVZiCbom for cache-block ops. Others (Svadu, Svpbmt, Svinval, Zfhmin, Zihintntl, Zihintpause) are absent. Thus no shipped target fully claims RVA22S64.

.dts linkage: the CPU riscv,isa string can only claim RVA22-compatible extensions that are implemented and verified; missing extensions must not be advertised.
