Vol II §5.6 — Traps

Canonical: specs/riscv-spec.html#_traps_2. Source line: specs/riscv-spec.html:82445. Domain: SPEC.

The H extension changes trap delivery: virtual interrupts and exceptions can be taken in VS-mode, and HS-mode can reflect them. vscause, vsepc, and vstval hold the guest trap state, while hstatus tracks the virtualization state at trap time. Trap priorities include hypervisor-specific causes such as guest-page faults and virtual instruction exceptions.

Spec quotation

"The hypervisor extension augments the trap cause encoding. Codes are
added for VS-level interrupts (interrupts 2, 6, 10), for supervisor-level
guest external interrupts (interrupt 12), for virtual-instruction
exceptions (exception 22), and for guest-page faults (exceptions 20, 21,
23). Furthermore, environment calls from VS-mode are assigned cause 10,
whereas those from HS-mode or S-mode use cause 9 as normal."
(specs/riscv-spec.html:82445-82455, anchor #_traps_2)

CVA6 status: absent. Trap handling in core/controller.sv supports only M/S/U cause codes; there are no guest-page-fault or virtual-instruction exception paths, no vscause/vsepc/vstval CSRs, and no hstatus-based virtualization-state save/restore.

.dts linkage: no hypervisor DT node; h is not present in the riscv,isa string.
