Vol II §10 — RISC-V Privileged Instruction Set Listings

Canonical: specs/riscv-spec.html#_risc_v_privileged_instruction_set_listings. Source line: specs/riscv-spec.html:89202.

This chapter provides compact instruction encodings for all privileged instructions (CSR access, MRET/SRET/URET/WFI, SFENCE.VMA, etc.). It is the reference for the decoder table that maps opcodes to control signals for the controller and CSR unit.

Spec quotation

"This chapter presents instruction-set listings for all instructions
defined in the RISC-V Privileged Architecture. The instruction-set
listings for unprivileged instructions, including the ECALL and EBREAK
instructions, are provided in Volume I, Appendix A."
(specs/riscv-spec.html:89202-89208, anchor #_risc_v_privileged_instruction_set_listings)

CVA6 status: implemented. The decoder recognizes privileged SYSTEM opcodes in core/decoder.sv and emits control signals for CSR read/write, MRET/SRET/WFI, ECALL/EBREAK, SFENCE.VMA/SINVAL.VMA, and FENCE.I. Execution is sequenced in core/controller.sv and core/csr_regfile.sv. The instruction encodings in this chapter map directly to the case statements in the decoder and the control flow in the controller.

.dts linkage: no direct DT node; the supported privileged operations are implied by the riscv,isa and mmu-type strings (e.g. S-mode, Sv39, Svpbmt).
