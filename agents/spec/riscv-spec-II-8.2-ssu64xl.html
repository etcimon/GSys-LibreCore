Vol II §8.2 — Ssu64xl Extension for UXLEN=64 Support, Version 1.0

Canonical: specs/riscv-spec.html#ssu64xl. Source line: specs/riscv-spec.html:88765. Domain: —.

Ssu64xl allows U-mode to use XLEN=64 on a core that supports variable XLEN, so user software runs as a 64-bit application. It is relevant for systems with dynamic XLEN switching (e.g. RV32/RV64 hybrids) and requires the CSR width and register file to support 64-bit U-mode.

Spec quotation

"If the Ssu64xl extension is implemented, then sstatus.UXL must be
capable of holding the value 2 (i.e., UXLEN=64 must be supported)."
(specs/riscv-spec.html:88765-88768, anchor #ssu64xl)

Pseudo-SystemVerilog synthesis notes

module ssu64xl (
  input  priv_lvl_e   priv_i,
  input  logic [1:0]  sxl_uxl_i,
  output logic [XLEN-1:0] effective_xlen_o
);
  // UXL field in mstatus/sstatus selects 32/64-bit mode for U-mode
endmodule

CVA6 status: absent. CVA6 targets are fixed XLEN: the CVA6Cfg.XLEN and VLEN are constants per target package in core/include/cv*a6*_config_pkg.sv; there is no dynamic UXL switching via sstatus.UXL in core/csr_regfile.sv.

.dts linkage: the DT riscv,isa string is fixed per target; no ssu64xl extension is advertised.
