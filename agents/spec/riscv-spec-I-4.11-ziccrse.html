Vol I §4.11 — Ziccrse Extension for Main Memory Reservability

Canonical: specs/riscv-spec.html#ext:ziccrse. Domain: RAM, SPEC.

Ziccrse ensures that main-memory regions with both coherence and cacheability PMAs must support the RsrvEventual PMA, i.e. that any naturally aligned power-of-two region up to the reservation-set size can support a load-reserved/store-conditional reservation. It is a prerequisite for the A/Zalrsc extensions and the WRS/WRS.NT instructions. Without it, LR/SC would not have a guaranteed memory region to monitor.

Spec quotation

"If the Ziccrse extension is implemented, then main memory regions with both
the coherence and cacheability PMAs must support the RsrvEventual PMA."
(specs/riscv-spec.html:10919-10923, anchor #ext:ziccrse / #norm:ziccrse_rsrv_eventual)

The WT cache path implements an SC backoff / pass-fail mechanism in core/cache_subsystem/wt_dcache_missunit.sv:334-347,576-583 and encodes LR/SC on the AXI interface in core/cache_subsystem/wt_axi_adapter.sv:252-267,577-580. The HPDcache path carries an explicit LR/SC reservation snoop between core/cache_subsystem/hpdcache/rtl/src/hpdcache_ctrl.sv:157-161,1179-1181 and hpdcache_uncached.sv:84-89,149-150.

.dts linkage: LR/SC usable only on main-memory regions that are both cacheable and coherent in the memory@ nodes, matching the CachedRegion PMA rules configured in core/include/config_pkg.sv.
