Vol II §7.4 — Svinval Extension for Fine-Grained Address-Translation Cache Invalidation

Canonical: specs/riscv-spec.html#ext:svinval. Source line: specs/riscv-spec.html:88388. Domain: RAM.

Svinval provides the SINVAL.VMA instruction, a fine-grained TLB invalidation operation, plus ordering instructions SFENCE.W.INVAL and SFENCE.INVAL.IR to fence its visibility. It allows TLB invalidations to be batched and synchronized with instruction fetches, reducing the cost of SFENCE.VMA.

Spec quotation

"The Svinval extension splits SFENCE.VMA, HFENCE.VVMA, and HFENCE.GVMA
instructions into finer-grained invalidation and ordering operations,
allowing TLB invalidations to be batched."
(specs/riscv-spec.html:88388-88392, anchor #ext:svinval)

CVA6 status: partial/absent. The base SFENCE.VMA is decoded and executed in core/decoder.sv/core/controller.sv to flush the TLB/PTW. The Svinval instructions (SINVAL.VMA, SFENCE.W.INVAL, SFENCE.INVAL.IR) are not separately decoded; if CVA6Cfg.RVSINVAL is set, verify decoder and fence logic.

.dts linkage: no DT node; Svinval availability is implied by the riscv,isa string and the TLB/PTW configuration.
