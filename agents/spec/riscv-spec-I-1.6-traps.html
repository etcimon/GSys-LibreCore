Vol I §1.6 — Exceptions, Traps, and Interrupts

Canonical: specs/riscv-spec.html#trap-defn. Domain: SPEC.

This subchapter defines the platform-neutral trap vocabulary: synchronous exceptions, interrupts, and the trap-handling model. It sets up the precise-trap contract that speculative execution must honor: no architectural state, memory, or CSR may become visible before in-order commit, and any exception must be reported at a well-defined instruction boundary. The definitions are elaborated in the Privileged Architecture (Volume II, chapters 3-5).

Pseudo-SystemVerilog synthesis notes

module trap_unit (
  input  logic ex_valid_i,           // exception detected in execute
  input  logic [VLEN-1:0] pc_i,
  output logic trap_o,               // precise trap to commit stage
  output logic [VLEN-1:0] trap_pc_o
);
  // trap reported only at commit boundary
endmodule
