Vol II §8.7 — Ssstrict Extension for Extension Conformance, Version 1.0

Canonical: specs/riscv-spec.html#ssstrict. Source line: specs/riscv-spec.html:88811. Domain: —.

Ssstrict tightens the behavior of reserved CSRs and instruction encodings so that unsupported CSR accesses trap and reserved opcodes raise illegal-instruction exceptions. It removes the option for implementations to silently ignore them, improving software portability and security.

Spec quotation

"If the Ssstrict extension is implemented, then no non-conforming
extensions are present. Furthermore, attempts to execute unimplemented
opcodes or access unimplemented CSRs in the standard or reserved
encoding spaces raises an illegal-instruction exception."
(specs/riscv-spec.html:88811-88817, anchor #ssstrict)
