Vol II §8.4 — Sstvecd Extension for Direct Trap Vectoring, Version 1.0

Canonical: specs/riscv-spec.html#sstvecd. Source line: specs/riscv-spec.html:88779. Domain: SPEC.

Sstvecd allows the trap vector base (stvec) to be set to any 4-byte aligned address, rather than requiring 64-byte alignment. It removes the MODE=Vectored alignment restriction and lets software use a single dispatch table at an arbitrary base.

Spec quotation

"If the Sstvecd extension is implemented, then stvec.MODE must be
capable of holding the value 0 (Direct). Furthermore, when
stvec.MODE=Direct, stvec.BASE must be capable of holding any valid
four-byte-aligned address."
(specs/riscv-spec.html:88779-88785, anchor #sstvecd)

CVA6 status: absent. The stvec CSR is implemented in core/csr_regfile.sv but there is no documented guarantee that stvec.BASE accepts any 4-byte-aligned address in Direct mode. Verify the WARL mask and trap vector construction in the csr_regfile and core/controller.sv before claiming Sstvecd.

.dts linkage: no DT node; Sstvecd capability would be reflected in the riscv,isa string.
