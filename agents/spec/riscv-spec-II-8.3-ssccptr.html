Vol II §8.3 — Ssccptr Extension for Main Memory Page-Table Reads, Version 1.0

Canonical: specs/riscv-spec.html#ssccptr. Source line: specs/riscv-spec.html:88772. Domain: RAM.

Ssccptr guarantees that page-table reads from main memory are coherent with respect to stores from the same hart, so the page-table walker does not observe stale PTE values after software updates a page table. This removes the need for explicit cache maintenance around PTE modifications and simplifies OS code.

Spec quotation

"If the Ssccptr extension is implemented, then main memory regions with
both the cacheability and coherence PMAs must support hardware page-table
reads."
(specs/riscv-spec.html:88772-88775, anchor #ssccptr)

CVA6 status: partial / implicit. The PTW in core/cva6_mmu/cva6_ptw.sv reads PTEs from the data cache or memory; in-order commit and coherent D$/write-through paths mean a same-hart PTE store should be visible. However, explicit Ssccptr conformance (main memory regions with cacheability+coherence PMAs guarantee hardware page-table reads) has not been verified or claimed.

.dts linkage: no dedicated DT node; Ssccptr behavior is implied by the memory@ PMA attributes (cacheable + coherent) for any region used for page tables.
