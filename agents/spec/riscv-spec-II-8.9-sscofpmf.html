Vol II §8.9 — Sscofpmf Extension for Count Overflow and Mode-Based Filtering

Canonical: specs/riscv-spec.html#Sscofpmf. Source line: specs/riscv-spec.html:88852. Domain: —.

Sscofpmf adds overflow status and interrupt facilities for performance counters, plus mode-based filtering (event counting enabled only in selected privilege modes). It uses mhpmevent bits and the scountovf CSR for S-mode visibility of overflow.

Spec quotation

"The current Privileged specification defines mhpmevent CSRs to select
and control event counting by the associated hpmcounter CSRs, but
provides no standardization of any fields within these CSRs. This
extension serves to accomplish exactly this within the existing mhpmevent
CSRs (and correspondingly avoids the unnecessary creation of whole new
sets of CSRs - past just one new CSR)."
(specs/riscv-spec.html:88852-88860, anchor #Sscofpmf)
