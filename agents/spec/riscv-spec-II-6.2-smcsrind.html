Vol II §6.2 — Smcsrind and Sscsrind Extensions for Indirect CSR Access

Canonical: specs/riscv-spec.html#indirect-csr. Source line: specs/riscv-spec.html:83960. Domain: —.

These extensions provide indirect CSR read/write instructions (csrind) that use a CSR index register to select one of a bank of CSRs. They are intended for accessing arrays of state (e.g. many performance counters or many PMP entries) without exhausting the 12-bit CSR address space.

Spec quotation

"Smcsrind/Sscsrind is an ISA extension that extends the indirect CSR
access mechanism originally defined as part of the Smaia/Ssaia
extensions, in order to make it available for use by other extensions
without creating an unnecessary dependence on Smaia/Ssaia."
(specs/riscv-spec.html:83960-83965, anchor #indirect-csr)

CVA6 status: absent. The CSR file in core/csr_regfile.sv uses direct 12-bit addresses; there is no indirect-index register or auto-increment CSR access mechanism.

.dts linkage: no DT node; Smcsrind/Sscsrind would be advertised in the riscv,isa string if implemented.
