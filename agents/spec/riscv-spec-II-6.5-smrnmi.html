Vol II §6.5 — Smrnmi Extension for Resumable Non-Maskable Interrupts

Canonical: specs/riscv-spec.html#rnmi. Source line: specs/riscv-spec.html:85026. Domain: SPEC.

Smrnmi provides resumable NMIs with dedicated CSRs (mnscratch, mnePc, mncause, mnstatus) that shadow the normal M-mode trap CSRs. The handler can return with mnret to resume the interrupted context. It requires the core to swap trap state without using the normal exception path.

Spec quotation

"The base machine-level architecture supports only unresumable
non-maskable interrupts (UNMIs), where the NMI jumps to a handler in
machine mode, overwriting the current mepc and mcause register values.
If the hart had been executing machine-mode code in a trap handler, the
previous values in mepc and mcause would not be recoverable and so
execution is not generally resumable."
(specs/riscv-spec.html:85026-85033, anchor #rnmi)
