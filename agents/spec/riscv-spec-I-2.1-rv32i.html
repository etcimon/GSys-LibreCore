Vol I §2.1 — RV32I Base Integer Instruction Set

Canonical: specs/riscv-spec.html#rv32. Domain: BP, RAM (control-transfer and load/store semantics).

RV32I defines the base 32-bit instructions, including the control-transfer instructions that the branch predictor must reproduce: conditional branches (BEQ/BNE/BLT/BLTU/BGE/BGEU), unconditional jumps (JAL/JALR), and the FENCE instruction for ordering. It also defines the load/store semantics (LB/LH/LW/LBU/LHU/SB/SH/SW) and the immediate encoding. Branch prediction is microarchitectural, but its correctness is judged against the exact control-flow results of this chapter; a predictor must not change the target or taken/not-taken outcome visible to the ISA.
