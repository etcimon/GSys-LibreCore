Vol I §5.9 — Zacas Extension for Atomic Compare-and-Swap (CAS) Instructions

Canonical: specs/riscv-spec.html#ext:zacas. Domain: SPEC, RAM.

Zacas adds AMOCAS.W/D/Q instructions that atomically load a data value from the address in rs1, compare the loaded value to the value held in rd, and, if bitwise equal, store the value in rs2 to the original address. The loaded value is placed into rd. The operation is atomic and supports acquire/release bits. It is a stronger primitive than LR/SC for lock-free algorithms and must be implemented with either a cache-level locked RMW or a bus-locked transaction.

Spec quotation

"For RV32, AMOCAS.W atomically loads a 32-bit data value from address in
rs1, compares the loaded value to the 32-bit value held in rd, and if
the comparison is bitwise equal, then stores the 32-bit value held in
rs2 to the original address in rs1. The value loaded from memory is
placed into register rd."
...
    temp = mem[X(rs1)]
    if ( temp == X(rd) )
        mem[X(rs1)] = X(rs2)
    X(rd) = temp
