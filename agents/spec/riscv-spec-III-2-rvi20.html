Vol III §2 — RVI20 Profiles

Canonical anchors: #_rvi20u32_profile (2.1), #_rvi20u64_profile (2.2). Source lines: specs/riscv-spec.html:90120 (2.1), :90233 (2.2).

RVI20 is the base integer-only profile: RVI20U32 requires RV32I, Zicsr, Zifencei, and the unprivileged base; RVI20U64 is the RV64 equivalent. It contains no M, A, F, D, or C extensions and is the minimum profile for cores that rely on software emulation for multiplication and atomics.

CVA6 status: configurable. CVA6 targets include RV32I and RV64I base packages (core/include/cv32a6*_config_pkg.sv and cv64a6*_config_pkg.sv), but shipped targets typically add M/A/F/D/C. A pure RVI20 configuration would clear RVA/RVF/RVD/RVC and ensure only Zicsr and Zifencei are set in core/include/config_pkg.sv.

.dts linkage: the CPU riscv,isa string would be rv32i_zicsr_zifencei or rv64i_zicsr_zifencei for a strict RVI20 configuration; the DT must not advertise M/A/F/D/C.
