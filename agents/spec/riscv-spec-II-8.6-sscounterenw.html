Vol II §8.6 — Sscounterenw Extension for Counter-Enable Writability, Version 1.0

Canonical: specs/riscv-spec.html#sscounterenw. Source line: specs/riscv-spec.html:88804. Domain: —.

Sscounterenw guarantees that scounteren is writable, allowing S-mode to control which counters are accessible to U-mode. It is a small CSR behavior requirement relevant to any core supporting S-mode with user-level counter access.

Spec quotation

"If the Sscounterenw extension is implemented, then for any hpmcounter
that is not read-only zero, the corresponding bit in scounteren must be
writable."
(specs/riscv-spec.html:88804-88807, anchor #sscounterenw)

Pseudo-SystemVerilog synthesis notes

module sscounterenw (
  input  logic        we_i,
  input  logic [XLEN-1:0] wdata_i,
  output logic [XLEN-1:0] scounteren_o

  // scounteren CSR writable from S-mode
endmodule

CVA6 status: partial. The performance counters and scounteren CSR are present in core/csr_regfile.sv and core/perf_counters.sv, but S-mode writability of every non-zero hpmcounter's corresponding scounteren bit should be verified.

.dts linkage: no DT node; Sscounterenw is a CSR behavior extension and has no direct device-tree property.
