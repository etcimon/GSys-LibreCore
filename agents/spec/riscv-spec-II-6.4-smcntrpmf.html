Vol II §6.4 — Smcntrpmf Cycle and Instret Privilege Mode Filtering

Canonical: specs/riscv-spec.html#smcntrpmf. Source line: specs/riscv-spec.html:84853. Domain: —.

Smcntrpmf adds counter-enable control bits that allow M-mode to filter cycle and instret counting by privilege mode. This lets the OS or hypervisor avoid counting cycles spent in firmware or other modes, improving the accuracy of user-level profiling.

Spec quotation

"The cycle and instret counters serve to support user mode self-
profiling usages, wherein a user can read the counter(s) twice and
compute the delta(s) to evaluate user software performance and
behavior. By default, these counters are not filtered by privilege mode,
and thus they continue to increment while traps to more privileged code
are handled. This causes unpredictable noise to the counter values
observed by the user."
(specs/riscv-spec.html:84853-84860, anchor #smcntrpmf)
