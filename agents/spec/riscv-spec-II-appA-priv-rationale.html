Vol II Appendix A — Historical Rationale for Extensions

Canonical: specs/riscv-spec.html#app:priv-rationale. Source line: specs/riscv-spec.html:89221.

This appendix provides historical rationale for the Smepmp extension. It is non-normative and not needed for implementation, but it clarifies design choices for PMP enhancements. No code locus is directly implied.

Spec quotation

"This appendix contains the rationale for RISC-V ISA extensions at the
time they were ratified. Unlike the ISA specification, this appendix is
ordered chronologically, so as to convey the motivation and
architectural reasoning underpinning each extension."
(specs/riscv-spec.html:89221-89226, anchor #app:priv-rationale)

CVA6 status: not applicable; reference material. The Smepmp implementation, where enabled, is in core/pmp/ and core/csr_regfile.sv (see agents/spec/riscv-spec-II-6.3-smepmp.html).

.dts linkage: no DT node; this appendix informs PMP region design and the memory@ / reserved-memory nodes protected by PMP.
