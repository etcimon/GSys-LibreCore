Vol III §5 — RVA23 Profiles

Canonical anchors: #_rva23u64_profile (5.1), #_rva23s64_profile (5.2). Source lines: specs/riscv-spec.html:91366 (5.1), :91701 (5.2).

RVA23 is the 2023 application-processor profile. It adds vector (V), scalar crypto (Zkn), and additional bit-manipulation/conditional extensions beyond RVA22. It tightens cache-block and CMO requirements. RVA23S64 keeps S-mode and advanced virtual-memory extensions. It is the target for modern Linux-capable cores.

Spec quotation

"The RVA23U64 profile specifies the ISA features available to user-mode
execution environments in 64-bit applications processors. This is the
most important profile within the application processor family in terms
of the amount of software that targets this profile."
...
"The RVA23S64 profile specifies the ISA features available to a
supervisor-mode execution environment in 64-bit applications processors.
RVA23S64 is based on privileged architecture version 1.13."

CVA6 status: partial. Vector is no longer purely absent: U10ᵇ attaches PULP Ara as the RVV unit behind EnableAccelerator / acc_dispatcher (CVA6Cfg.RVV, package cv64a6_server_math_v_config_pkg, corev_apu/src/g6lc_ara_attach.sv, vendor/ara/) — see Vol I ch9. That is still short of a full RVA23-mandated V profile (compliance cosim open; default DTS does not claim v). Scalar crypto (ZKN) AES is in core/aes.sv. Most other RVA23 extensions (advanced CMOs, Zicfilp/Zicfiss CFI, Ssaia, vector crypto zvk*, etc.) remain absent. No shipped target claims full RVA23U64/S64.

.dts linkage: the CPU riscv,isa string must not claim RVA23 unless every mandatory extension is present and verified; missing extensions should be omitted. Advertise v only when the _v package + Ara flist are the active build.
