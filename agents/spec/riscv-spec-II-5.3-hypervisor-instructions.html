Vol II §5.3 — Hypervisor Instructions

Canonical: specs/riscv-spec.html#_hypervisor_instructions. Source line: specs/riscv-spec.html:81519. Domain: —.

The H extension adds hypervisor instructions including HFENCE.VVMA, HFENCE.GVMA, HLV, HSV, and virtual-memory load/store instructions. HFENCE.* flush guest and host translation caches; HLV/HSV allow the hypervisor to access guest memory using guest virtual/physical addresses. These require a two-stage MMU and decode/execute integration.

Spec quotation

"The hypervisor extension adds virtual-machine load and store
instructions and two privileged fence instructions."
