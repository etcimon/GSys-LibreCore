# quantum_ai — cycle-function quantum registers and environmental intuition

A self-contained research package: one thesis, one reference implementation of
it, and the derivation the implementation's C interface rests on.

```
quantum_ai/
  cycle_function_intuition_thesis_final.pdf   the theory of record
  intuition_synthetics/                       worked example of the thesis
    include/qrc_full.h    quantum gate / qRAM C ABI
    include/qrc_env.h     environmental intuition C ABI
    include/qrc_humanoid.h virtual humanoid embodiment C ABI
  quantum_programming_theory/                 the basis of its C interface
  LICENSE                                     MIT (see "Licensing" below)
```

Everything here is **simulated**. No quantum hardware is involved, and none is
required to run any of it.

## The thesis

*Cycle-Function Quantum Registers and the Emergence of Environmental
Intuition — A C Abstraction for Photonic Universal Computation and Embodied
Recall* (Etienne Cimon, August 2026).

A photonic mode is constrained to amplitudes of the cubic form

```
C(P, Q; θ) = √P sin³θ + √Q cos³θ        P + Q = 1,  θ = ωt
|0⟩ ≡ C(1,0) = sin³θ        |1⟩ ≡ C(0,1) = cos³θ
|ψ⟩ = √P |0⟩ + e^{iφ} √Q |1⟩
```

The unusual cubic powers are chosen so that the algebra generated by
`{sin³, cos³}` stays **closed** under a universal gate set built from wave
plates, beam splitters and weak nonlinearities. The encoding is therefore not
merely a representation of a qubit — it is a cycle that never leaves its own
functional language.

The thesis then argues a second, sharper point. Expose that primitive through a
C interface, store an *environment* in quantum memory, and measure only a few
classical scalars per control tick, and a robot acquires the behavioural
signature of intuition: fluent action inside a world too large to re-search.
It insists that this signature is easily mistaken for understanding — and that
it remains **a discipline of late measurement, not a general mind**.

Section map: §2 defines the cycle function, §3 catalogues the universal gate set
in cycle-function form, §4 maps those gates onto the C interface, §5 the
measurement path into cryo-DRAM, §6 the four usage rules, §7 appearance of AGI
versus mechanism.

## `intuition_synthetics/` — the worked example

The thesis's §4–§6 made runnable. A Rust crate (`qrc_env`) that implements the
paper's C ABI and simulates the substrate underneath it, so the *shape* of the
interface can be programmed against today. It now also contains a **virtual
humanoid embodiment** stub: sensors, muscles, dual-circulatory and cervical
nervous system, exposed through `qrc_humanoid.h`.

```
intuition_synthetics/
  include/qrc_full.h     §4  the ABI: preg / lreg / qram, P_*, L_*, QRAM_*
  include/qrc_env.h      §6  the intuition layer: load, query, plan hint, remember
  include/qrc_humanoid.h    virtual humanoid embodiment: captors, motors, physiology
  src/cycle.rs              the cycle-function primitive and its gates
  src/qram.rs               classical stand-in for bucket-brigade qRAM
  src/intuition.rs          EnvWorld: kernel scoring, top-k query, plan hints
  src/anatomy.rs            canonical body tables: parts, regions, joints
  src/senses.rs             stereo camera, thermal and touch captor arrays
  src/motors.rs             hydraulic-tendon pulley motors and joints
  src/physiology.rs         dual-circulatory system + cervical nervous bus
  src/humanoid.rs           top-level integration
  src/ffi.rs                the C ABI for qrc_full, qrc_env and qrc_humanoid
  examples/warehouse.rs     a glance over a warehouse, in Rust
  examples/c_consumer.c     the same thing from C, against the cdylib
  examples/humanoid.rs      tick the virtual body and flex one elbow
```

`preg_t` is the direct link back to the theory — the register *is* the two rails
of the cycle function:

```c
typedef struct preg_t {
    alignas(64) double sin3[1];   /* the Prime rail, √P */
    alignas(64) double cos3[1];   /* the Ortho rail, √Q */
    uint64_t           mode_id;
    void*              hardware_ptr;
} preg_t;
```

The programmer never writes those coefficients. `P_H`, `P_X`, `P_Z`, `P_S`,
`P_T`, `P_RZ`, `P_CZ`, `P_CNOT`, `P_Toffoli` update them according to the
cycle-function equations catalogued in §3.

### Optimal usage (the thesis's four rules)

1. **Load once, query many.** The classical→qRAM transfer is the expensive
   boundary crossing; every later plan step must reuse the same superposition.
2. **Measure sparsely.** Top-k or amplitude estimation yields a handful of
   scalars that land in cryo-DRAM and are consumed by ordinary PID or MPC loops.
3. **Keep the residual classical.** Body state is low-dimensional and updates at
   kilohertz; encoding it into logical qubits every servo tick would destroy the
   latency budget.
4. **Treat quantum output as non-linear features.** The measured intuition
   vector is a projection of the whole stored world onto the current query —
   an embedding formed by interference instead of matrix multiplication.

In practice, for a robot tick:

```c
qrc_env_handle env = qrc_env_create(1 << 20);
qrc_env_load_batch(env, 0, keyframes, n);   /* once per site */

/* 1 kHz servo stays classical.  20–50 Hz planner: */
qrc_plan_hint h;
qrc_env_plan_hint(env, &pose, &h);
/* command next_foothold; steer off avoid */

if (slipped)
    qrc_env_remember_failure(env, &pose, severity);
```

Do **not** dump the map every tick. Full tomography of the environment state is
anti-optimal — it re-introduces the exponential cost the interface exists to
avoid. Measure only the hint.

### What this is not

Not AGI. Fluency over a stored world will look like understanding. Wipe the
handle and the palace leaves with it.

## `quantum_programming_theory/` — the basis of the C interface

Where the gate table the ABI implements is actually derived, and checked. A
conversational monograph (`index.html`, 73 turns) that works out the
Prime/Ortho picture of the cycle function, the per-gate cycle-function
equations, and the polarisation/Bloch correspondence — plus a validated model
and interactive figures.

The correspondence is direct:

| thesis / ABI | quantum_programming_theory |
|---|---|
| `preg_t.sin3` / `preg_t.cos3` | Prime (\|0⟩, horizontal) and Ortho (\|1⟩, vertical) rails |
| `P_*` / `L_*` gate entry points | the per-gate cycle-function equation tables |
| §3's universal set | the 16-gate registry in `js/qtheory.js` |
| the cycle function's geometry | the Bloch/Stokes mapping and the figures |

### Humanoid embodiment

`qrc_humanoid.h` extends the same cycle-function runtime to a virtual body:

| subsystem | stub contents |
|---|---|
| `src/anatomy.rs` | 20 parts, 11 regions, 24 joints with axis/purpose/motor tables |
| `src/senses.rs` | movable stereo camera with independent & combined eye focalization; thermal and touch arrays over every part |
| `src/motors.rs` | hydraulic-tendon, dented-compression, pulley-principle motors; one agonist + one antagonist per declared motor; angular momentum and compression distance per tendon |
| `src/physiology.rs` | liquid-nitrogen stator loop + oil rotor loop; zipper-ring cord-replacement port behind the neck; cervical-electrical star bus |
| `src/humanoid.rs` | tick loop: physiology → sensors → cervical bus → quantum query (if bound) → motor actuators |

The body is wired to the thesis's four rules exactly as the environment layer is:
load the world once, query for a sparse plan hint, keep the body state classical,
measure only the scalars the motors need.

`quantum_programming_theory` has its own README (`quantum_programming_theory/README.md`) covering the
figures and the 85-check validation against textbook quantum mechanics. Two
places where the source material contradicts itself are reconciled there, and
both matter to anyone reading the thesis alongside the code — see that file, and
`AGENTS.md` §4 here.
