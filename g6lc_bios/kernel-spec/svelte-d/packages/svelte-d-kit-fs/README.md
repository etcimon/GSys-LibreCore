bun + TypeScript consumer of `svelte-d`. Exercises SvelteKit **filesystem
routing** through `import { … } from 'svelte-d'`: `(groups)` stripped from the
URL, `[[optional]]` expanded to two `kit_router` registrations, and
`+layout.server.d` as a dest-unique vibe.0 class.
